⚙️ Guia de Configuração — Sistema de Indicadores EM Vidros

Siga as fases abaixo para ativar a sincronização automática com Google Sheets e o resumo semanal
1

API Key do n8n

Pendente
1
Abra o n8n no navegador
Acesse o endereço do sistema e faça login com seu usuário e senha.
O navegador vai mostrar aviso de certificado — clique em "Avançado" e "Continuar para o site".
2
Gere uma nova API Key
No menu lateral esquerdo: Settings → API → Create API Key. Dê o nome "Claude Code" e clique em Create.
3
Salve a key no arquivo de configuração do Claude
Copie a key gerada e peça ao Claude para salvar no settings.json — ou abra o arquivo e substitua o valor atual:
C:\Users\Livia.Lima\.claude\settings.json
→ campo "N8N_API_KEY": "COLE_A_NOVA_KEY_AQUI"
A nova key começa com n8n_api_... — se começar com eyJ, não é a key certa (é o token de sessão).
2

Planilha Google Sheets

Pendente
1
Crie a planilha no Google Drive
Acesse sheets.google.com → + Nova planilha → renomeie para "EM Vidros · Indicadores Diários".
2
Crie as 4 abas com os nomes exatos
Clique no + na parte inferior da planilha e crie as abas:
  • Viagens
  • Abastecimentos
  • Manutencoes (sem cedilha)
  • Quebras
Os nomes das abas precisam ser idênticos (incluindo maiúsculas/minúsculas) ao que está configurado nos workflows do n8n.
3
Copie o ID da planilha
A URL da planilha tem o formato:
https://docs.google.com/spreadsheets/d/ID_AQUI/edit
Copie o trecho entre /d/ e /edit — esse é o ID da planilha.
3

Importar Workflows no n8n

Pendente
1
Configurar credencial Google no n8n
No n8n: Credentials → Add Credential → Google Sheets OAuth2 API. Siga o fluxo de autenticação com sua conta Google.
2
Importar o Workflow de Registro
No n8n: Workflows → Import from File → selecione o arquivo:
G:\Meu Drive\LiviaOS\automacoes-compartilhadas\sistema-indicadores\n8n-workflow-registro.json
Em cada nó do Google Sheets, substitua COLE_AQUI_O_ID_DA_PLANILHA pelo ID copiado na Fase 2. Ative o workflow.
3
Importar o Workflow de Resumo Semanal
Mesmo processo com o arquivo:
G:\Meu Drive\LiviaOS\automacoes-compartilhadas\sistema-indicadores\n8n-workflow-resumo-semanal.json
Configure: ID da planilha, credencial Gmail (nó "Enviar E-mail"), e dados da API WhatsApp (nó "Enviar WhatsApp"). Ative o workflow.
4

Testar e Ativar

Pendente
1
Testar o formulário de registro
Abra formulario-registro.html, preencha uma viagem de teste e clique "Registrar". Verifique se aparece "sincronizado com o servidor" (em vez de "dados salvos localmente").
2
Verificar a planilha
Abra o Google Sheets e confirme que o registro de teste apareceu na aba "Viagens".
3
Executar o resumo semanal manualmente (teste)
No n8n, abra o Workflow "Resumo Semanal" e clique em Execute Workflow. Verifique o recebimento no e-mail e WhatsApp.
✅ Tudo funcionando? O sistema está ativo. O resumo vai chegar automaticamente toda sexta às 17h.
